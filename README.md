# FireFinder AI 🔥

Sistem deteksi dini kebakaran hutan menggunakan ConvLSTM dan Integrasi Satelit Real-time.

## Cara Install
1. Clone repository ini.
2. Install dependencies: `pip install -r requirements.txt`
3. Masuk ke folder frontend: `npm install`

## Catatan Penting
Model AI (`.h5`) dan Dataset (`.npy`) tidak disertakan di repository ini karena ukuran file yang besar.
Silakan generate data sendiri menggunakan script `mock_generator.py` atau hubungi pengembang untuk link Google Drive model.

## Setup API Key
Buka `api/config.py` dan masukkan API Key OpenWeatherMap & Gemini Anda sebelum menjalankan aplikasi.
